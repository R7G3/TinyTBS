# Архив: модель content pack (`.tinypack.zip`)

**Статус:** архив. Не канон.

## Почему архивировано

Модель «один ZIP-пак = опциональная матрёшка из всего контента + один активный пак»
не закрывала желания продукта:

- старая кампания + новые юниты;
- новая кампания + vanilla-юниты;
- рескин / «звёздные войны» без изоляции всего мира в одном паке;
- модули только с юнитами или только с theme.

Жёсткий «один активный пак» и оверрайд коротких id вели к усложнению
(наследование, форки, запрет unit-only) и всё равно ломали композицию.

**Актуальное решение:** библиотека модулей по ролям (`.tinymod.zip`) —
[CONTENT_MODULE_FORMAT.md](../CONTENT_MODULE_FORMAT.md), [adr/0008-content-modules.md](../adr/0008-content-modules.md).
