# Руководство автора контента

Это **подробный** гайд для игрока, который хочет сделать свою карту, уровень или мод. Текст намеренно разжёван: можно читать с нуля, даже если вы никогда не правили JSON и не писали код.

Технические схемы файлов — в других документах (ссылки в конце). Здесь — **в каком порядке нажимать кнопки** в игре и **что означают переключатели**.

Сначала соберите и запустите игру: [WELCOME.md](../WELCOME.md#как-собрать-и-запустить-из-исходников).

---

## Карта мира контента (простыми словами)

В TinyTBS контент живёт **модулями**. Модуль — папка (или zip) с понятной ролью:

| Тип модуля | Что внутри | Зачем |
|------------|------------|--------|
| **Scenario** | Карты, уровни, опционально кампания и скрипты | «Вселенная» партий: своя Схватка или цепочка уровней |
| **Units** | Типы юнитов (рыцарь, лучник…) | Новые или изменённые отряды |
| **Buildings** | Типы строений (замок, деревня…) | Новые или изменённые здания |
| **Theme** | Подмена картинок/звуков | Рескин без смены статов |
| **Bundle** (не модуль, а пресет) | Список module id + defaults | Быстрый выбор «набора» в Новой игре → Composition |

**Важная идея:** своя карта — это не отдельный «файл мира», а **scenario-модуль**. Внутри него: нарисовали **Map** (поле), повесили на него **Level** (кто играет, золото, победа), при желании собрали **Campaign** (порядок уровней).

Встроенный редактор умеет создавать и править всё это из меню **Редактор**, без сторонних программ для карт.

## Управление в редакторе (мышь, клавиатура, геймпад)

Почти везде работают и мышь, и клавиатура, и геймпад — можно менять устройство на ходу.

| Действие | Обычно |
|----------|--------|
| Движение по спискам / фокусу | Стрелки, WASD, D-pad / левый стик |
| Подтвердить / нажать кнопку | Enter, Space, кнопка A (низ на геймпаде) |
| Назад / закрыть | Escape, Backspace, кнопка B (право на геймпаде) |
| Переключить «зону» (лево ↔ право, панели) | Left/Right, **LB/RB** или **Q/E** (в подсказках на экране) |

На экране рисования карты зоны такие: **Content** (слева) → **Map** (поле) → **Tools** (справа). Переключайтесь LB/RB (или Q/E), чтобы фокус не «застрял» в списке, когда хотите кликать по клеткам.

Серые (disabled) кнопки **нельзя** нажать — сначала выполните условие (например, откройте scenario-модуль, чтобы появились New Map / New Level).

## Быстрый путь: своя Схватка за один вечер

Цель: новый scenario → карта → уровень → проверить в **Новая игра**.

### 1. Главное меню → Редактор

Откроется **Hub**: слева **Library** (ваши и встроенные модули), справа **Menu**.

Если библиотека пустая по user-модулям — это нормально: vanilla уже встроена в игру, а свои вещи появятся после создания.

### 2. Menu → New Scenario Module

Заполните простые поля (id, название…). Id лучше латиницей без пробелов (`my_islands`), как имя папки. Создайте модуль — он откроется в Hub (строка статуса подскажет, что открыто).

Пока модуль открыт, в Menu появляются действия именно для scenario: **New Map**, **New Level**, **Edit Campaign**, **Export Module**, **Close Module**.

> **Publish** в меню пока серый — сетевой каталог модов ещё не готов. Для обмена с друзьями используйте **Export Module**.

### 3. Menu → New Map

Задайте размер и стартовые параметры карты, создайте её. В Library у открытого scenario появятся карты; откройте карту в режим **рисования** (paint).

### 4. Рисуем карту (экран Paint)

**Левая панель — Content**

- Вкладки **Terrain / Buildings / Units** — что сейчас выбираете для кисти.
- Список иконок — конкретный тип (трава, дорога, замок, юнит…).

**Правая панель — Tools**

| Кнопка / блок | Смысл |
|---------------|--------|
| **Place (Add)** | Режим рисования: Confirm / клик по клетке **ставит** выбранное |
| **Erase (Delete)** | Режим стирания: убирает строение/юнита (и связанные вещи по правилам редактора) |
| **Owner** → Neutral, Player 1… | **Чей** будет поставленный замок/юнит. Neutral — ничейный (часто деревни). Player 1–4 — слоты игроков на карте |
| **Undo / Redo** | Отмена и повтор последних правок (есть и Ctrl+Z / Ctrl+Y) |
| **Validate** | Проверка карты: нет ли дыр в правилах (подсказка в статусе сверху; цветная точка = ок / предупреждение / ошибка) |
| **Save** | Записать карту на диск в ваш модуль |
| **Script** | Открыть/править скрипт карты (C#). Можно **пропустить** на первой карте |
| **Back** | Вернуться в Hub |

**Практика:**

1. Залейте большую часть поля **Grass**.
2. Добавьте **Water**, **Forest**, **Mountain**, **Road** — чтобы местность имела смысл в бою.
3. Поставьте **Castle** игроку 1 и игроку 2 (Owner → Player 1 / Player 2), чуть деревень (**Village**, Owner → Neutral или нужному игроку).
4. По желанию положите стартовых юнитов рядом с замками.
5. **Validate** → если ок → **Save**.

Не обязательно заполнять всё идеально с первого раза: сохранили — поиграли — вернулись и поправили.

### 5. Menu → New Level

**Level** — это «партия на этой карте»: ссылка на map, кто участвует, стартовое золото, лимиты, условия.

В редакторе уровня вы увидите двухколоночную форму. Типичный смысл полей (названия на экране могут быть на английском):

| Что правите | Зачем |
|-------------|--------|
| Id уровня | Имя папки уровня (`coast_skirmish`) |
| Ссылка на карту (`map.ref`) | Какую Map из **этого же** scenario использовать |
| Режим / теги (campaign / skirmish) | Чтобы уровень нашелся во вкладке Mode → … в Новой игре |
| Игроки / команды | Кто против кого; союзники не бьют друг друга |
| Золото, лимит юнитов | Старт экономики и потолок армии (в схватке часть этого можно ещё крутить в Lobby) |
| Победа / поражение | Когда матч заканчивается (канон правил — в геймдизайне; для первой карты часто хватает дефолтов) |

Нажмите **Save**, затем **Back** в Hub.

Без level ваша красивая map **не появится** в «Новая игра» как выбираемый уровень — map сама по себе доска, level — «запуск партии».

### 6. Проверка: Главное меню → Новая игра

Пройдите вкладки по порядку (Left/Right или клик по вкладкам):

1. **Mode** — Campaign или Skirmish (схватка). Для своей одиночной карты обычно **Skirmish**.
2. **Scenario** — выберите **ваш** scenario-модуль (не только vanilla).
3. **Level** — ваш новый уровень.
4. **Composition** — какой набор units / buildings / theme подставить в матч.
   - Часто достаточно **defaults сценария** или пресета **vanilla**.
   - Если вы сделали только карту на vanilla-юнитах — берите vanilla / defaults и не усложняйте.
   - Свой units-модуль появится в составе, когда вы его создадите и укажете в defaults или в bundle.
5. **Lobby** — кто сидит в креслах:
   - **Local** — человек за этим ПК;
   - **Bot · Easy / Bot · Normal** — ИИ (Confirm по слоту Bot **циклит** Easy ↔ Normal);
   - **Remote** — сеть, пока серым (недоступно);
   - **+** — добавить игрока; **X** — убрать (если ещё можно);
   - в схватке часто есть степперы **золота** и **unit cap** (±).
6. **Start** — загрузка и матч.

Поиграли → нашли кривую клетку → Редактор → открыли map → поправили → Save.

### 7. Поделиться с другом

В Hub при открытом **user**-модуле: **Export Module**.

Файл появится в `Downloads` внутри user data (см. [WELCOME.md](../WELCOME.md#где-лежат-ваши-данные)), обычно `{id}.tinymod.zip`.

Друг: **Контент** → Install **From device** → выбирает ваш zip → модуль встаёт в его библиотеку → **Новая игра**.

## Hub: что делает каждая кнопка Menu

Когда **ничего своего не открыто** (или открыт scenario), типичное меню:

| Кнопка | Значение |
|--------|----------|
| **New Scenario Module** | Новый сценарий (карты/уровни/кампания) |
| **New Units Module** | Новый каталог типов юнитов |
| **New Buildings Module** | Новый каталог строений |
| **New Theme Module** | Новый рескин (remap картинок) |
| **New Bundle** | Новый пресет Composition (список модулей + defaults) |
| **New Map** | Карта внутри **открытого** scenario |
| **New Level** | Уровень внутри **открытого** scenario |
| **Edit Campaign** | Порядок глав/уровней кампании в открытом scenario |
| **Export Module** | Упаковать открытый **user**-модуль в `.tinymod.zip` |
| **Close Module** | Закрыть текущий модуль, остаться в Hub |
| **Publish** | Пока недоступно (серый) |
| **Back** | Выход из редактора в главное меню |

**Library:** Confirm / клик по строке открывает модуль или объект (map / level / unit…). На bundled vanilla Confirm часто делает **копию в user** (чтобы править не «вшитое», а свою копию) — смотрите подсказку статуса на экране.

Когда открыт **units**-модуль, меню короткое: **New Unit**, Export, Close, Back. Аналогично buildings (**New Building**) и theme (**Edit Theme**).

## Юниты и строения (мастера типов)

1. Hub → **New Units Module** (или Buildings) → создайте модуль → он откроется.
2. **New Unit** / **New Building** → форма с полями статов, тегов, способностей.
3. **Save unit** / **Save building** — пишет JSON в модуль.
4. Чтобы юнит появился в матче, его модуль должен входить в **Composition** (defaults сценария или bundle). Карта может ссылаться на id вида `namespace/localId` — namespace по умолчанию совпадает с id модуля.

Подробности полей — [UNIT_FORMAT.md](../UNIT_FORMAT.md), [BUILDING_FORMAT.md](../BUILDING_FORMAT.md). Для картинок команды (цвет плаща/флага) — [ARTIST_GUIDE.md](../ARTIST_GUIDE.md) (**base + mask**).

Не обязательно рисовать своих спрайтов в первый день: можно начать с карты на vanilla-юнитах.

---

## Theme (рескин)

**New Theme Module** → **Edit Theme**: заголовок, версия, пути, **remaps** («этот логический id рисовать другими файлами»). Статы юнитов theme **не** меняет — только внешность/звук по задумке формата.

Сохранили → подключили theme в Composition вместе с units/buildings.

---

## Bundle (пресет состава)

**New Bundle** / правка user-bundle: список module id + defaults (какой scenario/units/buildings/theme подставлять «из коробки»).

В **Новая игра → Composition** пресеты видны рядом с defaults сценария. Удобно, если вы сделали пачку модулей «мир русалок» и хотите одним кликом собрать их вместе.

Удаление user-bundle также доступно из экрана **Контент**.

---

## Кампания

В открытом scenario: **Edit Campaign** — id кампании и **порядок глав** (уровней). Для одной схватки кампания **не обязательна**. Когда появится несколько levels — соберите из них цепочку и выбирайте Mode → **Campaign** в Новой игре.

---

## Скрипты карты

Кнопка **Script** на экране paint открывает редактор текста скрипта (C#). Скрипты умеют влиять на победу, события, экономику — но это уже следующий уровень сложности.

- Для первой карты **можно не открывать Script**.
- Если полезли в скрипты: читайте [SCRIPTING.md](../SCRIPTING.md). Игра проверяет опасные конструкции; «любой код» писать нельзя — только разрешённый API в песочнице.

---

## Экран «Контент» (библиотека у игрока)

Главное меню → **Контент**:

- вкладки модулей и bundles;
- подробности по Confirm;
- **Install → From device** — поставить чужой `.tinymod.zip`;
- Remove — убрать **user**-контент (вшитый vanilla не выкидывается как «ваш»);
- Download / From catalog — пока серые (сети нет).

Экспорт из редактора кладёт zip в **Downloads** user data — оттуда же удобно забирать файл для мессенджера/диска.

## Частые вопросы

**Почему моей карты нет в Новой игре?**  
Есть Map, но нет Level, или Level не того Mode (Campaign/Skirmish), или выбран не тот Scenario на второй вкладке.

**Почему юнит с карты «не тот» / ошибка состава?**  
Id на карте должен резолвиться в выбранной Composition. Свой мечтательный `my_mod/dragon` требует, чтобы units-модуль с этим типом входил в состав матча.

**Можно ли править vanilla напрямую?**  
Ориентир дизайна: дублировать bundled в user и править копию; Export/Share — своих user-модулей.

**Где физически файлы, если хочу бэкап?**  
`…/TinyTBS/Content/Modules/ваш_id/` в LocalApplicationData (Windows) или `~/.local/share/TinyTBS/` (Linux).

**Сломал модуль — что делать?**  
Не открывается — удалите user-модуль через Контент или папку с диска (сделайте копию на всякий случай). Vanilla в поставке игры останется.
