# Экраны, ввод и UI-поток

Канон представления и навигации. Правила хода юнита — [TURN_AND_UI.md](TURN_AND_UI.md).

## Ввод

- Логические действия (`GameCommand` и т.п.): **одна кнопка/жест на действие в рантайме**.
- В настройках — **три столбца** привязок на одно действие: клавиатура, геймпад, тач. Все устройства могут быть назначены сразу; игрок может сменить устройство mid-game без смены схемы действий.
- Геймпад: **positional** (позы как у Xbox-раскладки SDL), не по подписям на пластике. В подсказках UI — **иконки под бренд** (Xbox / PlayStation / Nintendo).
- Позы face-кнопок в матче:
  - **Низ (south)** — основное действие (выбор / подтверждение); на своём пустом замке — открыть магазин; на миникарте / целях — закрыть оверлей
  - **Право (east)** — на поле: открыть подробности клетки; во всплывающих окнах/меню — **назад / закрыть**
  - **Верх (north)** — «встать» / завершить ход юнита без атаки/захвата (в post-move)
- Клавиатура / мышь в матче (дефолт):
  - **Escape** / Start — пауза (открытие сразу); если открыты карта / цели / магазин / детали клетки — сначала закрывает их
  - **Enter / Space** — основное действие (как south); на миникарте / целях / деталях клетки — закрыть оверлей
  - **Правая кнопка мыши** — открыть подробности клетки (курсор на клетку под указателем)
  - **I** / east — подробности клетки на поле; во всплывающих окнах — назад / закрыть
  - **Backspace** — отмена / закрытие оверлея
- Карта, цели, детали клетки: без кнопки Close — east / Esc / south; также **любой клик мыши** в любом месте.
- Компактный виджет клетки — всегда на экране (угол); подробности — столбик «картинка слева / текст справа» по местности, строению, юниту.
- Навигация: WASD / стрелки; на паде — D-pad и левый стик. Выход в главное меню — **только пунктом «Меню» в паузе**, не по Escape/Back с поля.
- Тач — позже.

## Главное меню (состав)

Продолжить (если есть сохранения) · Новая игра · Загрузка · Контент · Редактор · Настройки · Об игре · Выход.

Фоны главного меню / настроек / загрузки / «Об игре»: изображение с плавным сдвигом (камера «летит» над полем). Идея матового стекла панелей — [ideas/ui-frosted-glass.md](../ideas/ui-frosted-glass.md).

### Новая игра

- Выбор **сценария**: кампании и skirmish из установленных **scenario**-модулей (+ свои scenario-модули).
- **Состав мира** (units / buildings / theme): по умолчанию из `scenario.defaults` или выбранного `*.bundle.json`; можно изменить. Конфликт одинаковых логических id в составе — нельзя. Типы на карте должны резолвиться — иначе старт с списком ошибок.
- **Локальная → Кампания:** кооп/**хотсит** (локальные игроки по очереди — рабочий сценарий без ИИ).
- **Локальная → Схватка:** команды, цвета, золото, лимит юнитов; «Добавить игрока»: локальный / бот; **«пригласить по сети» — greyed**.
- **Мультиплеер** — пункт есть, **greyed**.

### Загрузка / сохранения

Список от новых к старым; загрузить или удалить. «Продолжить» = самое свежее сохранение. Сейв хранит снимок модулей/версий — [SAVE_FORMAT.md](../SAVE_FORMAT.md).

### Контент (менеджер модулей)

Не «выбрать один активный пак», а **библиотека**: установить / удалить модули (`.tinymod.zip`); пресеты `Bundles/*.bundle.json`. **Скачать** / **Обновить** — greyed до сети.

Модель: [CONTENT_MODULE_FORMAT.md](../CONTENT_MODULE_FORMAT.md).

Политика скриптов: Уровень 1 + валидация текста по Уровню 2 — [SCRIPTING.md](../SCRIPTING.md).

### Редактор

**Проект (workspace)** — один или несколько модулей (`scenario` / `units` / `buildings` / `theme`). Shared Resources на время работы; при Save/Export — в `Resources/` модуля.

Создание карты игроком = **scenario-модуль** (можно дорастить).

Внутри scenario: карта, уровни, кампания, команды/игроки (метки), скрипт. Отдельные мастера для units / buildings / theme.

**Зафиксировано для v1:**

| Тема | Решение |
|------|---------|
| Playtest из редактора | **Не делаем** |
| Undo | **Да** |
| Копирование областей карты | **Нет** |
| Импорт ресурсов | Копировать в модуль; проверка base+mask |
| Shared в проекте | Да; при Save/Export разложить в модуль |
| Юниты / строения UI | Полный [UNIT_FORMAT](../UNIT_FORMAT.md) / [BUILDING_FORMAT](../BUILDING_FORMAT.md) |
| Скрипт карты | Текст + шаблон; fancy позже |
| Сохранение | Локально (проект / экспорт `.tinymod.zip`) |
| Опубликовать | Greyed (сеть) |
| Мастер «Новая карта» | Размер сетки |
| Команды и игроки | Метки; удаление → нейтрал; нейтрал = default / метка / «Удалить» |
| Валидация | Кнопка + перед Save; индикатор синий/зелёный/красный; ошибки **не** блокируют Save |
| Логические id | `{namespace}/{localId}`; дубликат полного id в модуле — ошибка |
| Namespace | По умолчанию = module.id |

#### Команды / игроки → метки на карте

1. Раздел «Команды и игроки»: создать команду, добавить игрока.
2. На карте панель `Team / Player` (+ **Нейтрал**).
3. Выбрать метку → помечать строения и юнитов.
4. Снять владельца: **Нейтрал** или **«Удалить»** в режиме разметки.
5. Удаление игрока/команды → объекты без владельца (нейтрал).

## Экран матча — каркас

| Зона | Содержимое |
|------|------------|
| **Сверху** | Статус-бар: фон цвета текущего игрока, золото, номер хода |
| **Центр** | Поле, курсор, контекстные метки **в уголках клеток** (атака и т.п.) |
| **Снизу** | Общие подсказки: меню (пауза), конец хода игрока и др. |

- Камера: следует за курсором у края **центральной зоны** (сторона зоны = ½ стороны экрана, поля по краям = ¼ стороны экрана). Зум: **nearest-neighbor**; bicubic — опционально позже через настройки.
- HP юнита — число справа внизу клетки; уровень — шеврон/звезда справа вверху.
- Виджет тайла под курсором — в углу, уезжает в другой угол, чтобы не перекрывать курсор; террейн + броня/скорость.
- Баннер в начале хода игрока: цвет игрока, номер хода, сумма дохода за ход.
- Надписи на поле — с обводкой для читаемости.

### Инфо о клетке

- **Компактный виджет** — всегда в углу (уезжает от курсора): местность + защита; при наличии — строение / юнит одной строкой.
- **Подробное окно** (как карта / цели): **I** / геймпад east / **ПКМ**. Текст по местности, строению и юниту; спрайты terrain + building/unit (base+mask цвета владельца). Закрытие: east / Esc / south.

### Покупка в замке

- Открытие: курсор на **своём** замке (клетка без выбранного юнита) + **основное действие** (south / Enter / Space / ЛКМ).
- Если на замке стоит **свой** юнит (можно выбрать для хода): вместо немедленного выбора/магазина — **краткое меню над клеткой** с двумя кнопками:
  - **->** — выбрать юнита (как обычный Confirm на юните)
  - **$** — открыть магазин
  - Закрытие меню: **east** / **I** / **ПКМ** / Esc (как назад); навигация и south/ЛКМ — по кнопкам
  - Фокус не уходит на общую кнопку **Menu** (она отключена, пока открыт оверлей)
- Окно магазина **по центру**, размер и поля как у **центральной зоны камеры** (где курсор двигается без следования камеры). Если не влезает — на всю ширину экрана и по высоте от статус-бара до нижней панели подсказок.
- Список по цене ↑; хватает золота — в цвете, нет — блёкло.
- Каждая позиция: **слева** спрайт юнита (base+mask цвета текущего игрока), **справа** название, цена и характеристики; клик / south по **всей** строке — покупка (отдельной кнопки Buy нет).
- Спавн на клетке замка, юнит **сразу выбран**. Если клетка занята — игрок **обязан** сходить новым юнитом, иначе не завершить ход этого юнита.

### Курсор и бой (кратко)

Подробнее поток хода — [TURN_AND_UI.md](TURN_AND_UI.md). После перемещения: цели атаки/захвата/ремонта, прыжки курсора по целям, отмена возврата, подтверждение осн. кнопкой; ремонт/захват сразу и юнит «походивший». Визуал атаки: лёгкая тряска, число урона, затем контратака тем же порядком отрисовки.

## Меню паузы (in-match)

Всплывающее окно **поверх геймплея** (матч на фоне). Пункты:

| Пункт | Поведение |
|-------|-----------|
| **Конец хода** | Завершить ход текущего игрока |
| **Карта** | Миникарта: весь уровень влезает в вид. Поверх клеток: **квадрат** цвета владельца постройки; **круг** цвета владельца юнита (если есть и постройка, и юнит — сначала квадрат, поверх круг). Памятный камень — миниатюра камня (не на постройках; если есть юнит — камень **под** кругом юнита) |
| **Цели** | Описание задания уровня, условия победы и поражения |
| **Сохранить / Загрузить** | Разрешено в **однопользовательских** партиях и в **хотсите** (несколько локальных игроков на одном устройстве). В **сетевой** партии — недоступно (когда сеть появится) |

| **Меню** | Выход в главное меню |

Открытие — с нижней панели общих подсказок («Меню»), **Escape** / Start, и/или привязки «Меню». Выход на главный экран — только пунктом **Меню** в этой таблице, не отдельной горячей клавишей с поля.

## Сеть (UI / продукт, зафиксировано)

- Тип игрока **Remote** зарезервирован в GDD.
- В UI закладываем **неактивные (greyed)** пункты (мультиплеер, «пригласить по сети», «Опубликовать» в редакторе, **Скачать** / **Обновить** в менеджере контента), чтобы вёрстка их учитывала.
- **Протокол / лобби / транспорт не проектируем**, пока не дойдём до сетевого этапа roadmap. Никаких решений lockstep/P2P и т.п. в каноне нет.
