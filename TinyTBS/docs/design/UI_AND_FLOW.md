# Экраны, ввод и UI-поток

Канон представления и навигации. Правила хода юнита — [TURN_AND_UI.md](TURN_AND_UI.md).

## Ввод

- Логические действия (`GameCommand` и т.п.): **одна кнопка/жест на действие в рантайме**.
- В настройках — **три столбца** привязок на одно действие: клавиатура, геймпад, тач. Все устройства могут быть назначены сразу; игрок может сменить устройство mid-game без смены схемы действий.
- Геймпад: **positional** (позы как у Xbox-раскладки SDL), не по подписям на пластике. В подсказках UI — **иконки под бренд** (Xbox / PlayStation / Nintendo).
- Позы face-кнопок в матче:
  - **Низ (south)** — основное действие (выбор / подтверждение)
  - **Право (east)** — дополнительное (инфо и т.п.)
  - **Верх (north)** — «встать» / завершить ход юнита без атаки/захвата (в post-move)
- Навигация: WASD / стрелки; на паде — D-pad и левый стик. Отмена/назад: Escape / Backspace (и соответствующая positional-кнопка пада по настройкам).
- Тач — позже.

## Главное меню (состав)

Продолжить (если есть сохранения) · Новая игра · Загрузка · Контент-паки · Редактор · Настройки · Об игре · Выход.

Фоны главного меню / настроек / загрузки / «Об игре»: изображение с плавным сдвигом (камера «летит» над полем). Идея матового стекла панелей — [ideas/ui-frosted-glass.md](../ideas/ui-frosted-glass.md).

### Новая игра

- **Локальная → Кампания:** список уровней; «добавить игрока» для кооператива/**хотсита** (локальные игроки по очереди — **рабочий** сценарий без ИИ).
- **Локальная → Схватка:** выбор уровня, команды, цвета войск/построек, стартовое золото, лимит юнитов. «Добавить игрока»: локальный игрок / бот; **«пригласить по сети» — неактивно (greyed), выбрать нельзя**.
- **Мультиплеер** — пункт в меню есть, пока **неактивен (greyed)**.

### Загрузка / сохранения

Список от новых к старым; загрузить или удалить. «Продолжить» = самое свежее сохранение.

### Контент-паки (экран меню)

Кнопки **Скачать**, **Обновить** (паки, для которых есть обновления); список установленных с выбором **активного** и **удалением**. Смысл паков — [GAME_DESIGN.md](../GAME_DESIGN.md) (content packs). Детали формата установки и источника загрузок — не зафиксированы в каноне (открытые вопросы вне docs).

### Редактор (экран меню)

Пункт есть. Задуманы действия Открыть / Сохранить (Опубликовать — позже) и вкладки: ресурсы (графика/аудио), юниты, кампания, уровень, карта (террейн, постройки, памятные камни, юниты, команды, игроки, скрипт). Детали пайплайна сохранения и UX v1 — не зафиксированы в каноне (открытые вопросы вне docs).

## Экран матча — каркас

| Зона | Содержимое |
|------|------------|
| **Сверху** | Статус-бар: фон цвета текущего игрока, золото, номер хода |
| **Центр** | Поле, курсор, контекстные метки **в уголках клеток** (атака и т.п.) |
| **Снизу** | Общие подсказки: меню (пауза), конец хода игрока и др. |

- Камера: следует за курсором у края **центральной зоны** (сторона зоны = ½ стороны экрана, поля по краям = ¼ стороны экрана). Зум: **nearest-neighbor**; bicubic — опционально позже через настройки.
- HP юнита — число справа внизу клетки; уровень — шеврон/звезда справа вверху.
- Виджет тайла под курсором — в углу, уезжает в другой угол, чтобы не перекрывать курсор; террейн + броня/скорость.
- Баннер в начале хода игрока: цвет игрока, номер хода, сумма дохода за ход.
- Надписи на поле — с обводкой для читаемости.

### Инфо (доп. кнопка)

- Чужой юнит / свой **неактивный**: панель юнита (статы, состояние, уровень) + местность.
- Если на клетке **здание** — также здание (base+mask цвета владельца, характеристики) + террейн.
- Осн. кнопка по своему неактивному — **ничего**.

### Покупка в замке

- Окно **по центру**, размер и поля как у **центральной зоны камеры** (где курсор двигается без следования камеры). Если не влезает — на всю ширину экрана и по высоте от статус-бара до нижней панели подсказок.
- Список по цене ↑; хватает золота — в цвете, нет — блёкло.
- Спавн на клетке замка, юнит **сразу выбран**. Если клетка занята — игрок **обязан** сходить новым юнитом, иначе не завершить ход этого юнита.

### Курсор и бой (кратко)

Подробнее поток хода — [TURN_AND_UI.md](TURN_AND_UI.md). После перемещения: цели атаки/захвата/ремонта, прыжки курсора по целям, отмена возврата, подтверждение осн. кнопкой; ремонт/захват сразу и юнит «походивший». Визуал атаки: лёгкая тряска, число урона, затем контратака тем же порядком отрисовки.

## Меню паузы (in-match)

Всплывающее окно **поверх геймплея** (матч на фоне). Пункты:

| Пункт | Поведение |
|-------|-----------|
| **Конец хода** | Завершить ход текущего игрока |
| **Карта** | Миникарта: весь уровень влезает в вид. Поверх клеток: **квадрат** цвета владельца постройки; **круг** цвета владельца юнита (если есть и постройка, и юнит — сначала квадрат, поверх круг). Памятный камень — миниатюра камня (не на постройках; если есть юнит — камень **под** кругом юнита) |
| **Цели** | Описание задания уровня, условия победы и поражения |
| **Сохранить / Загрузить** | Для **однопользовательских** партий (схватка без сети, кампания один игрок). В **сетевой** партии недоступно. Поведение в **хотсите** — см. открытые вопросы вне docs |
| **Меню** | Выход в главное меню |

Открытие — с нижней панели общих подсказок («Меню») и/или привязки «Меню».
