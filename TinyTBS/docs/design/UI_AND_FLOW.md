# Экраны, ввод и UI-поток

Канон представления и навигации. Правила хода юнита — [TURN_AND_UI.md](TURN_AND_UI.md).

## Ввод

- **Все интерактивные экраны и оверлеи** должны полностью управляться и **геймпадом**, и **мышью+клавиатурой** (можно сменить устройство mid-session). Фокус меню/оверлеев — через логические `GameCommand`, не через Gum `UseGamepadDefaults` (конфликт с D-pad/stick и scrollbar).
- Логические действия (`GameCommand` и т.п.): **одна кнопка/жест на действие в рантайме**.
- В настройках — **три столбца** привязок на одно действие: клавиатура, геймпад, тач. Все устройства могут быть назначены сразу; игрок может сменить устройство mid-game без смены схемы действий.
- Геймпад: **positional** (позы как у Xbox-раскладки SDL), не по подписям на пластике. В подсказках UI — **иконки под бренд** (Xbox / PlayStation / Nintendo).
- Позы face-кнопок в матче:
  - **Низ (south)** — основное действие (выбор / подтверждение); на своём пустом замке — открыть магазин; на миникарте / целях — закрыть оверлей
  - **Право (east)** — на поле: если юнит выбран — **снять выбор**; иначе открыть подробности клетки; во всплывающих окнах/меню — **назад / закрыть**
  - **Верх (north)** — «встать» / завершить ход юнита без атаки/захвата (`GameCommand.Wait`: Y на геймпаде / клавиша Y)
- Клавиатура / мышь в матче (дефолт):
  - **Escape** / Start — пауза; если открыты карта / цели / магазин / детали клетки — сначала закрывает их; если выбран юнит для хода — сначала **снимает выбор**, повторное нажатие — пауза
  - **Enter / Space** — основное действие (как south); на миникарте / целях / деталях клетки — закрыть оверлей
  - **Правая кнопка мыши** — открыть подробности клетки (курсор на клетку под указателем)
  - **ЛКМ** — короткий клик = основное действие; зажали и потащили = панорама (камера за направлением мыши)
  - **Колесо мыши вверх** — приблизить поле; **вниз** — отдалить
  - **Правый триггер геймпада** — приблизить (удержание); **левый триггер** — отдалить
  - **Правый стик** — панорама камеры (за направлением стика)
  - **I** / east — подробности клетки на поле (если юнит выбран — сначала снять выбор); во всплывающих окнах — назад / закрыть
  - **Backspace** — отмена / закрытие оверлея; на поле — снять выбор юнита
- Карта, цели, детали клетки: без кнопки Close — east / Esc / south; также **любой клик мыши** в любом месте.
- Компактный виджет клетки — всегда на экране (угол); подробности — столбик «картинка слева / текст справа» по местности, строению, юниту.
- Навигация: WASD / стрелки; на паде — D-pad и левый стик (камера подтягивается у края центральной зоны). Выход в главное меню — **только пунктом «Меню» в паузе**, не по Escape/Back с поля.
- Тач — позже.

## Главное меню (состав)

Продолжить (если есть сохранения) · Новая игра · Загрузка · Контент · Редактор · Настройки · Об игре · Выход.

**Сейчас в коде:** оболочка пунктов; **Новая игра** — вкладки Mode → Scenario → Level → Composition → Lobby (Left/Right как в Контенте; Start / Back); фильтр уровней по mode+scenario; composition = scenario defaults / bundle; лобби: слоты Local/Bot (кампания: P2 = Bot·Easy по умолчанию; Confirm на Bot циклит Easy/Normal) + **+**/X; схватка — ещё gold/unit cap → loading; **Контент** — панель-библиотека (Modules/Bundles; детальный попап + Remove; Install: From device через `IExternalFilePicker`, From catalog greyed; очередь `{UserData}/Downloads`; Download/Update greyed). **Продолжить** — live suspended матч (пауза → Main menu) иначе новейший match-сейв с диска; пауза: **Save**, **Leave match** (Dispose), **Main menu** (suspend). **Загрузка** / **Настройки** / Редактор / Об игре — greyed (следующий срез — Загрузка; затем campaigns / settings — см. [ARCHITECTURE](../ARCHITECTURE.md)).

Фоны главного меню / настроек / загрузки / «Об игре»: изображение с плавным сдвигом (камера «летит» над полем). Идея матового стекла панелей — [ideas/ui-frosted-glass.md](../ideas/ui-frosted-glass.md).

### Настройки

Пункт главного меню **Настройки** (и тот же экран из паузы позже — по желанию). Двойной ввод обязателен.

| Раздел | Содержание (канон / план) |
|--------|---------------------------|
| **Ввод** | Три столбца привязок на каждое `GameCommand`: клавиатура / геймпад / тач; смена устройства mid-session без смены схемы действий; геймпад positional; подсказки — иконки под бренд пада |
| **Графика** | Режим окна / разрешение (desktop); **UI scale** и при необходимости масштаб поля (`ui-scale-hidpi`); фильтр зума поля: **nearest-neighbor** по умолчанию, **bicubic** — опция |
| **Профиль** | Цвета игроков (пересечение с `player-colors` / лобби схватки); persist в user data |

Звук / язык / доступность — пока **не** зафиксированы в каноне; добавить отдельным решением, когда понадобятся.

План: `settings-ui` (+ `ui-scale-hidpi` в графике). Persist: JSON в `{UserData}` (точный файл — при реализации).

### Новая игра

- Вкладки (по порядку): **Mode** (Campaign / Skirmish) → **Scenario** (модули с уровнями выбранного mode) → **Level** (только уровни выбранного scenario + mode) → **Composition** (scenario.defaults или `*.bundle.json`) → **Lobby** (слоты игроков: Local / Bot / Remote; матч всегда пошаговый — отдельного режима «Hotseat» нет).
- **Слоты:** ряд на игрока — цвет · подпись · **X** (удалить; greyed у минимума игроков). Confirm по подписи слота **Bot** циклит Easy ↔ Normal. Внизу списка — **+** → chooser типа (**Local** / **Bot · Easy** / **Bot · Normal** / Remote greyed). Схватка: золото и unit cap. Кампания: те же слоты; по умолчанию P2 = Bot · Easy; золото и unit cap с уровня (без степперов).
- Нижняя панель: **Start** / **Back** (отдельного пункта Multiplayer нет — Remote только в chooser слота).
- Навигация: Up/Down по списку вкладки; Left/Right — вкладки (или нижние кнопки, если фокус на action bar); Confirm — выбор. На входе в Lobby фокус на первом слоте (подпись), чтобы шапка Players оставалась в кадре.

### Загрузка / сохранения

Список от новых к старым; загрузить или удалить. «Продолжить» = **сначала** незавершённый матч этой сессии (пауза → Main menu), иначе самое свежее match-сохранение. Сейв хранит снимок модулей/версий — [SAVE_FORMAT.md](../SAVE_FORMAT.md). Экран Загрузка — следующий срез.

### Контент (менеджер модулей)

Не «выбрать один активный пак», а **библиотека**: установить / удалить модули (`.tinymod.zip`); пресеты `Bundles/*.bundle.json`. **Скачать** / **Обновить** — greyed до сети.

Модель: [CONTENT_MODULE_FORMAT.md](../CONTENT_MODULE_FORMAT.md).

Политика скриптов: Уровень 1 + валидация текста по Уровню 2 — [SCRIPTING.md](../SCRIPTING.md).

### Редактор

**Проект (workspace)** — один или несколько модулей (`scenario` / `units` / `buildings` / `theme`). Shared Resources на время работы; при Save/Export — в `Resources/` модуля.

Создание карты игроком = **scenario-модуль** (можно дорастить).

Внутри scenario: карта, уровни, кампания, команды/игроки (метки), скрипт. Отдельные мастера для units / buildings / theme.

**Зафиксировано для v1:**

| Тема | Решение |
|------|---------|
| Playtest из редактора | **Не делаем** |
| Undo | **Да** |
| Копирование областей карты | **Нет** |
| Импорт ресурсов | Копировать в модуль; проверка base+mask |
| Shared в проекте | Да; при Save/Export разложить в модуль |
| Юниты / строения UI | Полный [UNIT_FORMAT](../UNIT_FORMAT.md) / [BUILDING_FORMAT](../BUILDING_FORMAT.md) |
| Скрипт карты | Текст + шаблон; fancy позже |
| Сохранение | Локально (проект / экспорт `.tinymod.zip`) |
| Опубликовать | Greyed (сеть) |
| Мастер «Новая карта» | Размер сетки |
| Команды и игроки | Метки; удаление → нейтрал; нейтрал = default / метка / «Удалить» |
| Валидация | Кнопка + перед Save; индикатор синий/зелёный/красный; ошибки **не** блокируют Save |
| Логические id | `{namespace}/{localId}`; дубликат полного id в модуле — ошибка |
| Namespace | По умолчанию = module.id |

#### Команды / игроки → метки на карте

1. Раздел «Команды и игроки»: создать команду, добавить игрока.
2. На карте панель `Team / Player` (+ **Нейтрал**).
3. Выбрать метку → помечать строения и юнитов.
4. Снять владельца: **Нейтрал** или **«Удалить»** в режиме разметки.
5. Удаление игрока/команды → объекты без владельца (нейтрал).

## Экран матча — каркас

| Зона | Содержимое |
|------|------------|
| **Сверху** | Статус-бар: фон цвета текущего игрока, золото, номер хода |
| **Центр** | Поле, курсор, контекстные метки **в уголках клеток** (атака и т.п.) |
| **Снизу** | Общие подсказки: меню (пауза), конец хода игрока и др. |

- Камера: следует за курсором у края **центральной зоны** (сторона зоны = ½ стороны экрана, поля по краям = ¼ стороны экрана). **Правый стик** геймпада — панорама (камера за направлением стика). **ЛКМ:** короткий клик = Confirm; зажали и потащили = панорама (камера за направлением мыши). Пока игрок панорамирует, курсор **остаётся на экране** и при необходимости сдвигается по клеткам. По краям карты допускается **1 тайл** пустого поля (с учётом зума), чтобы крайние клетки не прятались под UI. Зум: **nearest-neighbor**; bicubic — опционально позже через настройки.
- HP юнита — число справа внизу клетки; уровень — шеврон/звезда справа вверху.
- Виджет тайла под курсором — в углу, уезжает в другой угол, чтобы не перекрывать курсор; террейн + броня/скорость.
- Баннер в начале хода игрока: цвет игрока, номер хода, сумма дохода за ход.
- Надписи на поле — с обводкой для читаемости.

### Инфо о клетке

- **Компактный виджет** — всегда в углу (уезжает от курсора): местность + защита; при наличии — строение / юнит одной строкой.
- **Подробное окно** (как карта / цели): **I** / геймпад east / **ПКМ**. Текст по местности, строению и юниту; спрайты terrain + building/unit (base+mask цвета владельца). Закрытие: east / Esc / south.

### Покупка в замке

- Открытие: курсор на **своём** замке (клетка без выбранного юнита) + **основное действие** (south / Enter / Space / ЛКМ).
- Если на замке стоит **свой** юнит (можно выбрать для хода): вместо немедленного выбора/магазина — **краткое меню над клеткой** (вертикальный стек) с двумя кнопками:
  - **Move** — выбрать юнита (как обычный Confirm на юните)
  - **Buy** — открыть магазин
  - Закрытие меню: **east** / **I** / **ПКМ** / Esc (как назад); навигация **вверх/вниз** и south/ЛКМ — по кнопкам
  - Фокус не уходит на общую кнопку **Menu** (она отключена, пока открыт оверлей)
- Окно магазина **по центру**, размер и поля как у **центральной зоны камеры** (где курсор двигается без следования камеры). Если не влезает — на всю ширину экрана и по высоте от статус-бара до нижней панели подсказок.
- Список по цене ↑; хватает золота — в цвете, нет — блёкло.
- Каждая позиция: **слева** спрайт юнита (base+mask цвета текущего игрока), **справа** название, цена и характеристики; клик / south по **всей** строке — покупка (отдельной кнопки Buy нет).
- Спавн на клетке замка, юнит **сразу выбран**. Если клетка занята — игрок **обязан** сходить новым юнитом, иначе не завершить ход этого юнита.

### Курсор и бой (кратко)

Подробнее поток хода — [TURN_AND_UI.md](TURN_AND_UI.md). После перемещения: цели атаки/захвата/ремонта, прыжки курсора по целям, отмена возврата, подтверждение осн. кнопкой; ремонт/захват сразу и юнит «походивший». Визуал атаки: лёгкая тряска, число урона, затем контратака тем же порядком отрисовки. **Удержание** Confirm / ЛКМ на враге — превью его досягаемости на следующий ход (без действий за него).

## Меню паузы (in-match)

Всплывающее окно **поверх геймплея** (матч на фоне). Пункты:

| Пункт | Поведение |
|-------|-----------|
| **Конец хода** | Завершить ход текущего игрока |
| **Карта** | Миникарта: весь уровень влезает в вид. Поверх клеток: **квадрат** цвета владельца постройки; **круг** цвета владельца юнита (если есть и постройка, и юнит — сначала квадрат, поверх круг). Gravestone — миниатюра камня (не на постройках; если есть юнит — gravestone **под** кругом юнита) |
| **Цели** | Описание задания уровня, условия победы и поражения |
| **Сохранить** | Пишет `match_*.json` в `{UserData}/Saves/` (hotseat OK; сеть — позже greyed) |
| **Загрузить** | Greyed до среза «Загрузка» |
| **Продолжить** (Resume) | Закрыть паузу |
| **Main menu** | Suspend: главное меню без Dispose; **Continue** вернёт матч |
| **Leave match** | Полный выход: Dispose матча |

Открытие — с нижней панели общих подсказок («Меню»), **Escape** / Start, и/или привязки «Меню». Выход на главный экран без уничтожения матча — **Main menu**; полный выход — **Leave match**. После оверлея результата — только Dispose (как Leave).

### Результат матча

Когда сработало условие победы (`standard` или `SetVictory` скрипта), поверх поля — оверлей с победителем и кнопкой **Main menu** (Dispose). Ввод по полю и пауза заблокированы; закрыть оверлей иначе, чем выходом в меню, нельзя.

## Сеть (UI / продукт, зафиксировано)

- Тип игрока **Remote** зарезервирован в GDD и в chooser **Add player** (greyed).
- В UI закладываем **неактивные (greyed)** пункты (Remote в лобби, «Опубликовать» в редакторе, **Скачать** / **Обновить** в менеджере контента), чтобы вёрстка их учитывала.
- **Протокол / лобби / транспорт не проектируем**, пока не дойдём до сетевого этапа roadmap. Никаких решений lockstep/P2P и т.п. в каноне нет.

## Масштаб / разрешение

**Сейчас (код):**
- Gum: `EnableExpandToWindow(1f)` — canvas совпадает с back buffer попиксельно; при большем окне больше места, но **не** увеличенные контролы.
- Константы вёрстки и жестов (ширины панелей, шаг колёсика списка, высоты рядов) и базовый тайл карты (`MatchBoardLayout` 64 px, зум 0.5…2.5) заданы в **пикселях reference / back buffer**.
- Часть layout уже относительная (`%` от `CanvasWidth` / `CanvasHeight`); шрифт, кнопки Gum по умолчанию и фиксированные px — нет.

**Риск:** fullscreen / нативный 4K без UI scale → микрокнопки, микроскролл, мелкое поле (даже при ручном зуме карты потолок ограничен).

**План (`ui-scale-hidpi`, roadmap):**
1. Перейти с «expand 1:1» на политику масштаба Gum: **`EnableZoomToWindow`** под reference (ориентир **1280×720**) и/или `ExpandToWindow(defaultZoom)` на HiDPI — чтобы авторские px оставались reference-единицами.
2. В **Настройки → Графика** — множитель **UI scale** (и при необходимости отдельно масштаб поля). См. [§ Настройки](#настройки).
3. Для матча — стартовый / авто-зум тайлов под viewport (не только ручной зум колёсиком).
4. Жесты вроде шага скролла списка считать в **reference px** (или долях на тот же UI zoom), не в «сырых» пикселях 4K.

Детали вариантов — [ideas/ui-scale-hidpi.md](../ideas/ui-scale-hidpi.md). Реализация вместе с или сразу после `settings-ui`; не блокирует combat/economy.
