# Ход и управление юнитами

Канон: [GAME_DESIGN.md](../GAME_DESIGN.md). Экраны / HUD / пауза: [UI_AND_FLOW.md](UI_AND_FLOW.md). Пиксельная вёрстка Gum — не здесь.

## Активность

- В начале хода игрока все его юниты **активны**.
- Активный юнит может перемещаться и/или выполнять действие (атака, захват, способность).
- Типичный порядок: **ход → действие**. После действия юнит **неактивен** (даже если не ходил).
- Неактивный юнит визуально **затемнён** (серый оттенок) — см. artist/dimFactor в архитектуре.
- Действие не обязательно: можно только походить или сразу завершить ход юнита.

## Действия по клеткам (без контекстного меню)

После выбора юнита действия задаются **Confirm / кликом по клетке** (подсветка досягаемости / атаки / подъёма):

| Клетка | Действие |
|--------|----------|
| Своя клетка юнита | Если под ним захват/ремонт доступен — **захват или ремонт**; иначе **завершить ход** юнита (wait) |
| Враг / destroyable в радиусе | Атака / разрушение |
| Соседний gravestone (ведьма) | Поднять скелета |
| Пустая досягаемая | Ход (один раз за активацию) |

**Отмена перемещения:** `GameCommand.Cancel` / Backspace, east (B/Info) или Esc при выбранном юните — снимает выбор и **возвращает** юнита на клетку до хода, если он уже сдвигался. Y (`GameCommand.Wait`) — завершить активацию без атаки.

Замок с юнитом поверх: отдельный floater Move / Buy (не post-move меню).

## Катапульта и подобные

Способность `moveOrAttackExclusive`: за активацию либо перемещение, либо атака — не оба.

Юнит, исчерпавший возможности или получивший «конец хода юнита», неактивен до следующего хода владельца.
