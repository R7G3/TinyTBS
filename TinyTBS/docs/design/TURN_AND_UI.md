# Ход и управление юнитами

Канон: [GAME_DESIGN.md](../GAME_DESIGN.md). Пиксельная вёрстка UI — не здесь (слой представления).

## Активность

- В начале хода игрока все его юниты **активны**.
- Активный юнит может перемещаться и/или выполнять действие (атака, захват, способность).
- Типичный порядок: **ход → действие**. После действия юнит **неактивен** (даже если не ходил).
- Неактивный юнит визуально **затемнён** (серый оттенок) — см. artist/dimFactor в архитектуре.
- Действие не обязательно: можно только походить или сразу завершить ход юнита.

## Катапульта и подобные

Способность `moveOrAttackOnly`: за активацию либо перемещение, либо атака — не оба.

## Контекстное меню

Если у выбранного юнита есть доступные действия (или он уже сдвинут и действия доступны), меню:

- продолжить/задать перемещение;
- доступное действие (подпись контекстна: атаковать / захватить / возродить / …);
- закончить ход этим юнитом;
- отменить перемещение (если было);
- **приостановить действие** — подтвердили клетку хода, действие отложили, можно сделать позже в том же ходу игрока.

Юнит, исчерпавший возможности или получивший «конец хода юнита», неактивен до следующего хода владельца.
