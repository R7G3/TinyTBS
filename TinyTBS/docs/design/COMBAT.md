# Бой, опыт, памятный камень

Канон: [GAME_DESIGN.md](../GAME_DESIGN.md).

## Формула урона

Промежуточные значения **вещественные**. Один `Floor` в конце. Если результат &lt; 0 → **0**.

### Бонус уровня (к статам)

| Уровень | % к атаке и к защите (от **базы** юнита) |
|---------|------------------------------------------|
| 0 | 0% |
| 1 | 10% |
| 2 | 20% |
| 3 | 30% |

```text
levelAtkAdd = Attack  × levelAttackPercent    // 65 × 0.10 = 6.5
levelDefAdd = Defence × levelDefencePercent
```

Процент **не** применяется к аурам и бонусам местности/строений.

### Сборка

```text
atk = Attack + levelAtkAdd + (клетка атакующего в ауре союзного Духа ? 5 : 0)

def = Defence + levelDefAdd
    + защита местности под защитником
    + защита строения под защитником   // разрушенная деревня: 0

diff = atk − def
damage = Floor( diff × special × (Health / 10.0) )
if damage < 0: damage = 0
```

`Health / 10.0` — вещественное деление (HP 95 → 9.5).

### `special` (один коэффициент)

Берутся правила атакующего юнита (data-driven). **Первое совпадение** побеждает.

Канон лучника:

1. Цель с тегом **flying** → `1.4` (в т.ч. с соседней клетки: взлёта/приземления нет, бой с летающим всегда «дальний»).
2. Иначе манхэттенская дистанция **1** (сосед по стороне) → `0.8`.
3. Иначе → `1.0`.

### Пример

Мечник L1 (45/5, HP 100) vs Def 5 на траве, без ауры, `special=1`:

`atk=49.5`, `def=5.5`, `diff=44`, `Floor(44×1×10)=440`.

Масштаб при полном HP большой — цифры статов можно балансить позже.

## Контратака

- Если атакующий бьёт с **соседней** клетки (манхэттен 1), защитник контратакует (если может).
- Порядок: урон атаки → показ → урон контратаки → показ.
- Число контратак за ход не ограничено.
- Катапульта **никогда** не контратакует.
- Лучник на дистанции **2–3** не получает ответный урон (не контратака на него).

## Опыт и уровни

| Действие | XP |
|----------|-----|
| Атака или контратака, враг выжил | +1 |
| Убийство | +2 |

Пороги: L1 = 2 XP, L2 = 4, L3 = 6 (накопленный опыт для достижения уровня; L0 с появления).

Бонусы — см. таблицу % выше (и к атаке, и к защите).

Отображение: L0 скрыт; L1 одна шеврон-галка вверх; L2 две; L3 золотая звезда.

Повторный найм Короля: опыт и уровень **сбрасываются**.

## Памятный камень

- Появляется на клетке убитого юнита, **кроме** скелета и духа.
- Не на клетке со строением.
- Без владельца.
- Живёт с хода появления до **следующего хода того же игрока включительно**.
- Ведьма на **соседней** клетке может бесплатно поднять союзного скелета; камень уничтожается.
- Ведьма за ход: перемещение и затем **либо** атака, **либо** подъём.
- Поднять скелета может ведьма **любого** игрока со своего камня-соседа (свой союзный скелет).

Правила камня — логика/баланс; на карте опционально только **стартовые экземпляры**.
