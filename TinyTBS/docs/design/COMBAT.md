# Бой, опыт, gravestone

Канон: [GAME_DESIGN.md](../GAME_DESIGN.md).

## Формула урона

Промежуточные значения **вещественные**. Один `Floor` в конце. Если результат &lt; 0 → **0**.

### Бонус уровня (к статам)

| Уровень | Бонус к атаке | Бонус к защите |
|---------|---------------|----------------|
| 0 | 0 | 0 |
| 1 | +2 | 0 |
| 2 | +4 | 0 |
| … | +2 × уровень | 0 |
| 9 | +18 | 0 |

```text
levelAtkAdd = 2 × Level    // L0 → 0, L3 → 6
levelDefAdd = 0
```

Бонус уровня **не** применяется к аурам и бонусам местности/строений (аура — отдельный слагаемый к atk).

### Сборка

```text
atk = Attack + levelAtkAdd + (клетка атакующего в ауре союзного Духа ? value способности attackAura : 0)

def = Defence
    + защита местности под защитником
    + защита строения под защитником   // только Def; к Atk строение не даёт ничего
                                           // ruined: defenceBonus из ruined (vanilla деревня 10)

diff = atk − def
healthFraction = CurrentHP / MaxHP    // 100/100 → 1.0, 67/100 → 0.67
damage = Floor( diff × special × healthFraction )
if damage < 0: damage = 0
```

`healthFraction` — вещественное деление текущего HP атакующего на его максимум. Раненый бьёт слабее; при полном HP множитель = 1 (нет «шашечных» ваншотов от `/10`).

### `special` (один коэффициент)

Берутся правила атакующего юнита (data-driven). **Первое совпадение** побеждает.

Канон лучника:

1. Цель с тегом **flying** → `1.4` (в т.ч. с соседней клетки: взлёта/приземления нет, бой с летающим всегда «дальний»).
2. Иначе манхэттенская дистанция **1** (сосед по стороне) → `0.8`.
3. Иначе → `1.0`.

### Пример

Мечник L0 (45 atk) бьёт мечника на траве в деревне (def 5+5+15=25), оба на 100 HP, без ауры, `special=1`:

`diff=20`, `healthFraction=1`, `Floor(20×1×1)=20`.

Тот же атакующий на 67 HP: `Floor(20×1×0.67)=13`.

## Контратака

- Если атакующий бьёт с **соседней** клетки (манхэттен 1), защитник контратакует (если может).
- Порядок: урон атаки → показ → урон контратаки → показ.
- Число контратак за ход не ограничено.
- Катапульта **никогда** не контратакует.
- Лучник на дистанции **2–3** не получает ответный урон (не контратака на него).

## Опыт и уровни

| Действие | XP |
|----------|-----|
| Атака или контратака, враг выжил | +1 |
| Убийство | +2 |

Пороги (накопленный XP): L1 = 2, L2 = 4, … L9 = 18 (`2 × уровень`). Макс. уровень **9**. L0 с появления.

Бонусы — см. таблицу выше (только атака).

Отображение: L0 на поле **скрыт**; L1–L9 — **цифра** в левом нижнем углу клетки (без шевронов). Текущее **HP** — числом в правом нижнем углу. В окне деталей клетки уровень и бонус атаки показываются всегда.

Повторный найм Короля: опыт и уровень **сбрасываются**.

## Gravestone

- Появляется на клетке убитого юнита, **кроме** скелета и духа.
- Не на клетке со строением.
- Без владельца.
- Живёт с хода появления до **следующего хода того же игрока включительно**.
- Ведьма на **соседней** клетке может бесплатно поднять союзного скелета; gravestone уничтожается.
- Ведьма за ход: перемещение и затем **либо** атака, **либо** подъём.
- Поднять скелета может ведьма **любого** игрока со своего gravestone-соседа (свой союзный скелет).

Правила gravestone — логика/баланс; на карте опционально только **стартовые экземпляры**.
