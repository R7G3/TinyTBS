# UI / поле: масштаб под HiDPI и 4K

- **Статус:** idea (направление зафиксировано в каноне; реализация — позже)
- **Дата:** 2026-09-27
- **Контекст:** константы вёрстки и тайлов в пикселях back buffer; Gum `EnableExpandToWindow(1f)` → на 4K UI и клетки визуально мельчают
- **Канон:** [UI_AND_FLOW § Масштаб / разрешение](../design/UI_AND_FLOW.md#масштаб--разрешение)
- **План:** `ui-scale-hidpi` (внутри / сразу после `settings-ui`) в [ARCHITECTURE](../ARCHITECTURE.md) и `.cursor/plans/структура_tinytbs_*.plan.md`

## Зачем

Игрок на нативном 4K / HiDPI без UI scale получает микрокнопки, микроскролл списков и мелкую карту. Reference-дизайн (≈1280×720) должен оставаться читаемым при любом размере окна.

## Варианты (Gum)

| Подход | Смысл | Заметки |
|--------|--------|---------|
| `EnableZoomToWindow` под 1280×720 | Canvas в logical units; zoom растёт с окном | Предпочтительный дефолт для меню/HUD |
| `EnableExpandToWindow(defaultZoom: N)` | Больше места + базовый множитель | Удобно как HiDPI-пресет |
| Ручной `ClientSizeChanged` + свой zoom | Полный контроль (clamp, letterbox) | Если встроенных хелперов мало |
| Оставить expand 1:1 + только `%` layout | Больше пространства, те же px контролов | **Недостаточно** — шрифт/кнопки остаются мелкими |

## Варианты (матч / поле)

| Подход | Смысл |
|--------|--------|
| Авто-зум при входе / resize | `TileSize` под долю viewport (с clamp min/max) |
| Только ручной зум (сейчас) | На 4K потолок `MaxZoom` может быть мал |
| Отдельный «Board scale» в настройках | Независимо от UI scale |

## Рекомендация на реализацию

1. Сменить политику Gum на **zoom-to-window** (reference 1280×720) или expand + `defaultZoom` по DPI/высоте.
2. Добавить в Настройки множитель **UI scale**.
3. Жесты (шаг скролла списка и т.п.) — в reference px / после деления на UI zoom.
4. Для поля — стартовый или авто-зум + при необходимости поднять `MaxZoom` / отдельный board scale.

Не делать ad-hoc `* 2` в каждом экране.

## Когда вернуться

Рядом с экраном **Настройки** / полировкой графики; не блокирует `match-combat-gdd` / economy. Желательно до широкого теста на 4K.
