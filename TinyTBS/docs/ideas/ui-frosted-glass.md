# UI: зернистое стекло (frosted / grainy glass) на фонах панелей

- **Статус:** idea  
- **Дата:** 2026-09-15  
- **Контекст:** меню / оверлеи Gum поверх сцены или фона

## Зачем

Матовые полупрозрачные панели с лёгким зерном вместо плоского scrim — читаемее и «дороже» на вид, особенно на главном меню и паузе.

## Варианты

| Подход | Сложность | Нагрузка на кадр | Заметки |
|--------|-----------|------------------|---------|
| Scrim + tiled noise PNG | низкая | ничтожная | Достаточно для пиксель-TBS меню |
| То же + заранее размытый фон в ассете | низкая | нет (только текстура) | Нет живого blur |
| Realtime: сцена → RT → blur → панель + grain | средняя+ | умеренная (1–2 pass; desktop 720p–1080p обычно ок) | Нужен, если фон за UI живой (матч) |
| Шейдер на каждый виджет Gum | высокая | от площади панелей | Избыточно на старте |

Gum из коробки frosted glass не даёт: blur/зерно — слой под деревом Gum или кастомный visual.

## Рекомендация на сейчас

Пока **не делать** realtime blur. Когда дойдём до полировки меню: сначала **fake** (scrim + noise). Realtime — только если fake недостаточно и фон анимирован.

## Когда вернуться

После playable loop / полировки UI (не блокирует map loader и GDD-матч).
