# ADR 0004: Перекраска спрайтов — base + mask PNG

## Статус

Принято

## Контекст

До 10 игроков + нейтральный цвет; цвета выбирает игрок; состояния «может действовать» / «уже походил» (затемнение). Нельзя хранить 11×2 вариантов каждого юнита и строения.

## Решение

- Для юнитов и строений с цветом команды: **`_base.png`** + **`_team.png`** (или несколько `_mask_*.png`).
- Цвет игрока — **tint** при `SpriteBatch.Draw` на маску.
- Затемнение — **`Color * dimFactor`**, без отдельных файлов.

## Альтернативы

- **Шейдер** с маркерными цветами — опционально позже.
- **CPU bake** текстур — только опциональный кэш, не по умолчанию.

## Последствия

- Правила для художника: [ARTIST_GUIDE.md](../ARTIST_GUIDE.md)
- Моды подменяют те же пары файлов в `Mods/{Name}/Images/`.
