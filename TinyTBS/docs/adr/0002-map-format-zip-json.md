# ADR 0002: Формат карты — ZIP + JSON

## Статус

Принято

## Контекст

Нужен переносимый контейнер: описание тайлов, скрипт, опциональные ассеты. Рассматривались gzip и XML.

## Решение

- **ZIP** — `System.IO.Compression.ZipArchive`, несколько файлов, кросс-платформенно.
- **JSON** — `map.json`, слои `surface`, `buildings`, `units`.
- **script.cs** — логика карты в том же архиве.

Расширение: `.map.zip` или `.tbsmap`.

## Альтернативы

- **Gzip** — один поток, неудобен для нескольких файлов.
- **XML** — отклонён в пользу JSON для редактора и diff.

## Последствия

- Спецификация: [MAP_FORMAT.md](../MAP_FORMAT.md)
- Загрузка через `IFileContentProvider`, не Content Builder.
