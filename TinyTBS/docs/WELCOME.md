# Добро пожаловать в TinyTBS

Короткий вход для игроков и авторов контента. Технический канон для разработчиков — в [GAME_DESIGN.md](GAME_DESIGN.md) и соседних документах; здесь — «зачем играть», «на чём пойдёт» и «как собрать / сделать свой контент».

## Что это за игра

**TinyTBS** — пошаговая стратегия с упором на тактику, а не на удачу.

Каждый удар считается одинаково в одинаковой ситуации: без бросков кубика, без «критов из ниоткуда». Раненый отряд бьёт слабее — ветеранов хочется беречь, а добивания и лечение становятся частью плана, а не косметикой. Горы, леса, дороги и вода реально меняют скорость и защиту: замок на высоте — твердыня, болото — ловушка для тяжёлой кавалерии. Деревни дают золото, замки — найм; иногда важнее удержать экономику, чем гнаться за каждым убийством.

Сюда же встроен **редактор всего нужного для модов и своих партий**: сценарии, карты, уровни, кампании, юниты, строения, темы оформления и пресеты состава контента. Нарисовал карту — сохранил — запустил схватку с ботами или с другом за одним ПК.

Если хочется глубже в правила боя и экономики — [GAME_DESIGN.md](GAME_DESIGN.md).

## Системные требования

Замеры на одной машине (ориентир, не лабораторный тест): Ryzen 5 5600X, RX 6700 XT, стандартное разрешение окна — матч с **4 ботами Normal** держал процессор в пике около **~10%**, видеокарту около **~1.7%**, оперативную память игры около **300–350 МБ**.

| | Минимум (оценка) | Комфортно |
|--|--|--|
| **CPU** | Intel N100, Ryzen 3 2200G, Core i3 примерно 6–7 поколения или аналог | любой современный 4+ ядра |
| **ОЗУ** | 2 ГБ свободно под игру + ОС (пик самой игры ~350 МБ) | 4 ГБ+ у системы в целом |
| **Видео** | любая встройка с рабочим **OpenGL 2.0+** (Intel UHD 600, Vega 3 и старше) | дискретная карта не нужна |
| **ОС** | **Windows 10+** или **любой современный дистрибутив Linux** с **glibc 2.27+** (например Ubuntu 22.04+, Debian 12+, SteamOS 3+) | то же |

Отдельной «минимальной версии ядра Linux» нет: ориентируйтесь на дистрибутив и glibc. Нужны обычный рабочий стол (X11 или Wayland), актуальные GPU-драйверы (часто Mesa) и звук через PulseAudio / PipeWire.

**Готовых установочных пакетов пока нет** — игру собирают из исходников (см. ниже). Для сборки нужен **.NET 10 SDK**. Отдельно ставить MonoGame или SDL игроку не требуется: нативные библиотеки подтягиваются вместе с проектом.

## Как собрать и запустить из исходников

Репозиторий содержит два проектоподобных каталога; **рабочий MonoGame-solution** лежит в папке `TinyTBS/` (рядом может быть Unity-эксперимент — его не трогаем).

### Что поставить заранее

1. [Git](https://git-scm.com/)
2. [.NET 10 SDK](https://dotnet.microsoft.com/download) (`dotnet --version` должен показать 10.x)

На Linux обычно достаточно пакета SDK из [официальных инструкций Microsoft](https://learn.microsoft.com/dotnet/core/install/linux) для вашего дистрибутива.

### Windows (PowerShell или cmd)

```bat
cd TinyTBS
dotnet build TinyTBS.Desktop/TinyTBS.Desktop.csproj
dotnet run --project TinyTBS.Desktop/TinyTBS.Desktop.csproj
```

Первая сборка скачает NuGet-пакеты и прогонит Content Builder (картинки → `.xnb`) — это нормально и может занять минуту.

### Linux (bash)

Те же команды:

```bash
cd TinyTBS
dotnet build TinyTBS.Desktop/TinyTBS.Desktop.csproj
dotnet run --project TinyTBS.Desktop/TinyTBS.Desktop.csproj
```

Если окно не открывается или падает на графике — проверьте драйверы Mesa / вендора GPU и что сессия не «голая» консоль без OpenGL. Отдельно устанавливать `libsdl2` ради TinyTBS обычно не нужно: SDL и OpenAL Soft приходят с MonoGame DesktopGL.

### Где лежат ваши данные

После первого запуска пользовательские модули, сейвы и экспорты оказываются в каталоге приложения:

| ОС | Типичный путь |
|----|----------------|
| Windows | `%LocalAppData%\TinyTBS\` |
| Linux | `~/.local/share/TinyTBS/` |

Внутри: `Content/Modules/`, `Content/Bundles/`, `Saves/`, `Downloads/` (сюда же падает **Export Module** → `.tinymod.zip`).
